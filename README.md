# Uday Kumar B — Cinematic Portfolio

A cinematic React + Vite portfolio for Uday Kumar B, focused on Software Engineering, Cloud, DevOps and Automation.

## Run locally

```bash
npm install
npm run dev
```

## Build locally

```bash
npm run build
npm run preview
```

## GitHub Pages deployment

This project is prepared for a **GitHub user site** repository named:

`udaykumarbijinepalli.github.io`

The included GitHub Actions workflow automatically builds and deploys the site whenever changes are pushed to `main`.

After the first successful workflow, the portfolio will be available at:

`https://udaykumarbijinepalli.github.io/`

## Updating the resume

The live resume is stored as `public/resume.pdf`. To update it later, replace that one file with your latest PDF using the same filename, then commit and push the change to `main`. GitHub Actions will redeploy the portfolio automatically.

The contact section downloads it as `Uday-Kumar-B-Resume.pdf`.
